# رسا اجوکیشن · Rasa Education

برنامه‌ریز هوشمند درسی برای دانش‌آموزان ایرانی؛ آفلاین، رمزگذاری‌شده روی خود دستگاه، و پایهٔ یک سامانهٔ آموزشی بزرگ‌تر (حساب والد و دانش‌آموز، همگام‌سازی اختیاری، کتابخانهٔ جزوه‌های تعاملی).

## امکانات نسخهٔ فعلی (فاز ۱)

- **برنامه‌ریز هوشمند هفتگی:** بلوک‌های مطالعه / مرور / آزمونک بر اساس زمان آزاد هر روز، ضریب و ضعف هر درس، آزمون‌های نزدیک و مرورهای موعددار؛ با توضیح «چرا این برنامه؟».
- **ثبت مطالعه:** تایمر پومودورو و آزاد، ثبت دستی، نمودار ۱۴ روزه، هفتگی و سهم درس‌ها.
- **تحلیل آزمون:** ثبت تراز، رتبه و درصد هر درس؛ نمودار افت‌وخیز و پیش‌بینی تراز آزمون بعدی.
- **To-Do روزانه** با درصد پیشرفت و **مرور فاصله‌دار** (۱/۳/۷/۱۶/۳۰ روز).
- **انگیزش:** استریک، نقشهٔ پایداری یک‌ساله (شبیه گیت‌هاب)، سطح و امتیاز، نشان‌ها.
- **تقویم شمسی** ماهانه، رویدادها (آزمون، کلاس، مهلت، مشاوره) و یادآورهای تکرارشونده با اعلان.
- **کتابخانهٔ رسا:** پیش‌نمایش جزوه‌های تعاملی با آزمونک رایگان که مستقیم به مرور فاصله‌دار وصل می‌شود.
- **گزارش** چاپی A4 / PDF و فایل HTML قابل ارسال برای والد یا مشاور.
- **امنیت:** چند حساب با نام کاربری و رمز، رمزگذاری AES-256-GCM (PBKDF2-SHA256)، قفل خودکار.
- **پشتیبان:** نسخه‌های تاریخ‌دار خودکار و دستی، بازگردانی، خروجی و ورود فایل رمزدار `.mstbak`.
- تم‌های «رسا · شب»، «رسا · روز»، کهکشانی و اقیانوس؛ موبایل‌محور و راست‌به‌چپ؛ فونت وزیرمتن داخل فایل.

## ساختار مخزن

```
apps/planner/        اپ برنامه‌ریز (منبع)
  src/core.js        ابزارها، تقویم جلالی، رمزنگاری، ذخیره‌سازی، نمودارها
  src/app.js         مدل داده، موتور هوشمند، حساب‌ها، پشتیبان، یادآور، تایمر
  src/views.js       صفحه‌ها، کتابخانه، گزارش، رویدادها
  src/style.css      سیستم طراحی پایه      src/rasa.css  لایهٔ برند رسا
  build.mjs          ساخت فایل تکی و PWA
content/catalog.json فهرست جزوه‌ها و آزمونک‌ها (منبع کتابخانه)
brand/               لوگو و برندبوک
docs/                اسناد زنده: چشم‌انداز، برند، معماری، نقشهٔ راه، محتوا، مدل درآمد، امنیت، ADR
dist/                خروجی ساخته‌شده (فایل تکی + وب‌اپ)
```

## ساخت

```bash
node apps/planner/build.mjs   # Node 18+؛ بدون وابستگی
```

خروجی: `dist/rasa-planner.html` و پوشهٔ `dist/web/` (همراه `manifest` و `service worker`). با هر push به `main`، وب‌اپ از طریق GitHub Actions روی GitHub Pages منتشر می‌شود.
