# کتابخانه و فروشگاه جزوه‌های تعاملی
> وضعیت: پیش‌نمایش در فاز ۱؛ فروش در فاز ۳ · آخرین بازبینی: ۱۲ آبان ۱۴۰۵

## ایده
هر محصول رسا «قابل اجرا» است، نه فقط PDF: آزمونک، فلش‌کارت، نقشهٔ ذهنی یا قالب برنامه، و نتیجه‌اش مستقیم وارد برنامه‌ریز می‌شود (مبحث → مرور فاصله‌دار؛ قالب → ضریب درس‌ها؛ آزمونک → نقاط ضعف).
الهام ارائه از کارت‌های محصول rasa-prompt.ir: شماره، تصویر، عنوان، توضیح، برچسب، «نمونه، فایل و مجوز».

## انواع محصول
| نوع | کارکرد در برنامه |
|---|---|
| جزوهٔ تعاملی + آزمونک | آزمونک فوری → افزودن مبحث به مرور فاصله‌دار |
| نقشهٔ ذهنی | مرور سریع؛ پرسش‌های مفهومی |
| فلش‌کارت | مرور فاصله‌دار در سطح کارت |
| فرمول‌نامه | مرجع سریع + دام‌های تستی |
| قالب برنامه | تنظیم درس‌ها و ضرایب برای رشته/هدف |
| بستهٔ آمادگی | برنامهٔ چندهفته‌ای + گزارش والد |

## قالب داده — `content/catalog.json`
```json
{
  "levels": [{"id": "m2", "name": "متوسطه دوم"}],
  "items": [{
    "id": "deriv-12", "level": "m2", "subject": "ریاضی", "kind": "جزوهٔ تعاملی + آزمونک",
    "glyph": "f′", "title": "…", "desc": "…", "price": "نمونهٔ رایگان", "status": "پیش‌نمایش",
    "topic": "قواعد مشتق",
    "quiz": [{"q": "…", "o": ["…"], "a": 0, "ex": "توضیح اختیاری"}],
    "template": [["زیست‌شناسی", 4]]
  }]
}
```
- `quiz` اختیاری: پرسش چهارگزینه‌ای، `a` اندیس پاسخ درست.
- `template` اختیاری: `[نام درس، ضریب]`.
- محتوای آزمونک‌ها باید پیش از انتشار توسط معلم متخصص بازبینی شود.

## منابع رسمی و مجوز
- کتاب‌های درسی رسمی را سازمان پژوهش و برنامه‌ریزی آموزشی در chap.sch.ir منتشر می‌کند؛ رسا فقط **پیوند** می‌دهد و تا دریافت مجوز، فایل‌ها را بازنشر نمی‌کند.
- محتوای رسا تألیفی است؛ هر محصول مجوز استفاده و منبع روشن دارد.

## جریان خرید (فاز ۳)
کاتالوگ → صفحهٔ محصول با نمونهٔ رایگان → پرداخت با درگاه ایرانی یا اشتراک خانوادگی → مجوز امضاشده روی حساب → دانلود و اجرای آفلاین.
