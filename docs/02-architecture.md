# معماری
> وضعیت: فاز ۱ پیاده‌سازی‌شده؛ فاز ۲ طراحی · آخرین بازبینی: ۱۲ آبان ۱۴۰۵

## فاز ۱ — فایل تکی (پیاده‌سازی‌شده)
- **بدون وابستگی و بدون سرور.** `build.mjs` فونت، CSS، کاتالوگ و JS را درون یک HTML می‌گذارد.
- **ذخیره‌سازی:** IndexedDB (پایگاه `mst-study`، store `kv`) با بازگشت به localStorage (پیشوند `kv:`).
  - `vault:<user>` → کل وضعیت کاربر، رمزگذاری‌شده.
  - `bk:<user>:<id>` → نسخه‌های پشتیبان، رمزگذاری‌شده.
  - `localStorage['mst.users']` → فهرست کاربران (نام کاربری، salt، تعداد دور PBKDF2) بدون هیچ دادهٔ درسی.
- **رمزنگاری:** WebCrypto؛ AES-256-GCM با IV تصادفی ۱۲ بایتی؛ کلید از رمز با PBKDF2-SHA256 (۲۱۰٬۰۰۰ دور، salt ۱۶ بایتی).
- **PWA:** نسخهٔ `dist/web` با manifest و service worker (cache-first) روی GitHub Pages؛ نسخهٔ تکی بدون SW هم کامل کار می‌کند.

### ماژول‌ها
| فایل | مسئولیت |
|---|---|
| `core.js` | DOM helpers، اعداد فارسی، تقویم جلالی، رمزنگاری، KV، نمودارهای SVG (ستونی، خطی، دونات، هیت‌مپ)، بزرگ‌نمایی/جدول/CSV، انتخابگر تاریخ شمسی |
| `app.js` | مدل داده، تجمیع‌ها، استریک، XP، **موتور اولویت و برنامه‌ریز**، پیش‌بینی تراز، پشتیبان، حساب‌ها، یادآور، تایمر، تم |
| `views.js` | ناوبری، صفحه‌ها، کتابخانه و آزمونک، گزارش، رویدادهای رابط (`data-a` / `data-f` / `data-c`) |

### موتور هوشمند
امتیاز هر درس = `ضریب × (۱ + ۱٫۵·ضعف + ۰٫۸·غفلت + ۱٫۲·فوریت)`؛
ضعف از میانگین سه آزمون اخیر، غفلت از روزهای مطالعه‌نشده، فوریت از نزدیکی آزمون (۳۰ روز). سهم هدف هر درس متناسب با امتیاز است و برنامه‌ریز بلوک‌ها را با الگوریتم «بیشترین کسری» پخش می‌کند، با جریمهٔ تکرار پیاپی و تقدم مرورهای موعددار.

## فاز ۲ — سامانه (طراحی)
```
[اپ دانش‌آموز PWA/Android]──┐                ┌──[اپ والد]
   IndexedDB/SQLite محلی     │  داده رمزدار   │  فقط خواندن + تأیید هدف/جایزه
                             ▼                ▼
                     سرور همگام‌سازی کوچک (میزبانی ایران)
                     - فقط blobهای رمزگذاری‌شده + فراداده
                     - احراز هویت با شماره موبایل + OTP
                     - کاتالوگ محتوا و مجوز خرید
                     - صف گزارش هفتگی (پیامک / بله / ایتا)
```
- **کلیدها:** دادهٔ دانش‌آموز با کلید خودش رمز می‌شود؛ برای والد یک «کلید اشتراک» جدا (با تبادل از طریق QR) ساخته می‌شود تا سرور هرگز متن خام نبیند.
- **همگام‌سازی:** نسخه‌بندی هر رکورد (LWW با ساعت منطقی) روی همان ساختار KV؛ پشتیبان‌ها همچنان محلی.
- **اپ اندروید/ویندوز:** همین کد داخل پوستهٔ Capacitor/Tauri با SQLite.
- **فروشگاه:** کاتالوگ `content/catalog.json` به API تبدیل می‌شود؛ محتوای خریداری‌شده با مجوز امضاشده باز می‌شود.
