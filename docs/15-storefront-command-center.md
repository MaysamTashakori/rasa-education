# ۱۵ · فروشگاه و مرکز فرمان

> سند زنده؛ وضعیت پیاده‌سازی واقعی در `server/store.mjs`، `server/admin.mjs` و `apps/site`.

## نشانی‌ها
| مسیر | کاربرد |
|---|---|
| `/` | صفحهٔ اول رسا آموزش |
| `/c` و `/c/<دسته>` | کاتالوگ با جست‌وجو، دسته و نوع |
| `/p/<id>` | صفحهٔ محصول با پیش‌نمایش زنده |
| `/p/<id>/preview` | فایل محصول در sandbox (همه) |
| `/p/<id>/open`، `/download` | فقط برای دارندهٔ محصول |
| `/me` | کتابخانه، کارنامه، ذخیره‌ها، سفارش‌ها، پشتیبانی، دعوت، اطلاعیه |
| `/creators` | موتور سازندگان و درخواست همکاری |
| `/admin/<بخش>` | مرکز فرمان (فقط نقش‌های تیم) |
| `/kids/`، `/planner/` | سامانهٔ کلاس دوم و برنامه‌ریز |

## نقش‌ها
`founder` (همه‌چیز، تعیین نقش، تأیید کار ایجنت) · `admin` · `editor` (محصول، دسته، نظر) · `support` (تیکت، CRM) · `marketer` (کمپین، اطلاعیه، CRM) · `creator` · `customer`.
اولین کاربر ثبت‌نام‌شده یا هر شناسه در `FOUNDER_LOGINS` بنیان‌گذار می‌شود.

## خرید
همه‌چیز فعلاً رایگان است: «دریافت رایگان» یا سبد ← سفارش `paid-free` با مبلغ صفر ← کتابخانه. جدول‌ها: `store_orders`، `store_order_items`، `owned`. درگاه پرداخت بعداً به همین سفارش‌ها وصل می‌شود.

## کارنامه از درس تعاملی
درس HTML در پایان آزمونک این پیام را می‌فرستد و کارنامهٔ روایی ساخته می‌شود:
```js
parent.postMessage({type: 'rasa:result', score: 8, total: 10, learner: 'نام', topics: [{name: 'محور عدد', score: 4, total: 5}]}, '*')
```

## مرکز فرمان
نمای کلی (KPI، روند ۳۰ روزه، منبع ورود، پرطرفدارها) · محصولات (ویرایش و آپلود نسخه‌دار تا ۴۰MB) · دسته‌بندی درختی · CRM (برچسب، یادداشت، نقش، تاریخچهٔ رویداد) · تیکت‌ها (پیش‌نویس پاسخ با ایجنت) · نظرها (بازبینی) · اطلاع‌رسانی · بازاریابی (کمپین با `utm_source`، قیف، پست شبکه‌های اجتماعی) · ایجنت‌ها (۱۹ ایجنت، کلید توقف، بودجهٔ توکن، صف تأیید) · دفتر ممیزی.

## ایجنت‌ها و دروازهٔ هوش مصنوعی
- متغیرها: `AI_API_KEY`، `AI_BASE_URL` (پیش‌فرض OpenAI؛ هر سرویس سازگار)، `AI_MODEL` (پیش‌فرض `gpt-4o-mini`).
- بدون کلید، ایجنت‌ها پیش‌نویس قالبی می‌سازند و با برچسب «قالبی» مشخص می‌شوند.
- هر خروجی ایجنت `review` است تا بنیان‌گذار تأیید یا رد کند؛ تأیید پاسخ تیکت، آن را برای کاربر می‌فرستد.
- وظایف فعلی: `marketer:social`، `support:reply`، `report-writer:weekly`، `qa:catalog`، `growth:digest`.
