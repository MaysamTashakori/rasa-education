# خدمات SaaS و AIaaS
> وضعیت: طرح · آخرین بازبینی: ۱۵ آبان ۱۴۰۵ · فعلاً همه‌چیز رایگان است (تصمیم بنیان‌گذار)

## SaaS — پلتفرم برای دیگران
| بسته | مخاطب | امکانات |
|---|---|---|
| **خانواده** | والد و فرزندان | سامانهٔ کلاس، برنامه‌ریز، کتابخانه، کارنامه، اعلان بله/تلگرام |
| **معلم** | معلم خصوصی/کلاس | فضای کلاس، تکلیف از بازار، کارنامهٔ کلاسی، گزارش به والدین |
| **مدرسه/آموزشگاه** | مدیر مدرسه | مستأجر جدا، برند مدرسه، ثبت‌نام گروهی، داشبورد مدیریتی، نقش‌ها |
| **سازنده** | معلم/ناشر | استودیو، انتشار در بازار، آمار فروش، تسویه |

## AIaaS — هوش آموزشی به‌عنوان سرویس
API با کلید، سهمیه و ثبت هزینه (از مسیر `ai-gateway`):
| سرویس | ورودی | خروجی |
|---|---|---|
| `POST /v1/booklets/draft` | پایه، درس، سرفصل | پیش‌نویس جزوهٔ گام‌به‌گام (manifest استاندارد) |
| `POST /v1/quizzes/generate` | اهداف، سطح دشواری | آزمون با کلید و توضیح |
| `POST /v1/report-cards` | نتایج آزمون‌ها | کارنامهٔ روایی + نمودار |
| `POST /v1/plans` | زمان آزاد، اهداف، ضعف‌ها | برنامهٔ هفتگی با دلیل |
| `POST /v1/feedback` | پاسخ دانش‌آموز | بازخورد گام‌به‌گام |

قواعد: هیچ خروجی برای کودک بدون بازبینی منتشر نمی‌شود. دادهٔ مشتری برای آموزش مدل استفاده نمی‌شود. سهمیه و هزینه برای هر کلید شفاف است.

## مدل درآمد آینده (پس از دورهٔ رایگان)
- هستهٔ رایگان برای همیشه: سامانهٔ روزانه، چند درس در هر پایه، کارنامهٔ پایه.
- درآمد: محصولات ویژهٔ بازار (کمیسیون از سازنده)، اشتراک خانوادهٔ پیشرفته (گزارش عمیق و مربی هوشمند)، SaaS مدرسه (به ازای دانش‌آموز)، AIaaS (به ازای مصرف).
