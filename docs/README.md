# اسناد زنده

این پوشه «منبع حقیقت» محصول است و همراه کد تغییر می‌کند.

## قواعد زنده‌ماندن اسناد
1. هر تغییر رفتاری در کد، در همان commit یا PR سند مربوط را به‌روز می‌کند.
2. هر سند در سرآغاز خود «وضعیت» و «آخرین بازبینی» دارد.
3. تصمیم‌های مهم و برگشت‌ناپذیر به صورت ADR در [`adr/`](adr/) ثبت می‌شوند (هرگز حذف نمی‌شوند؛ فقط «جایگزین‌شده» می‌شوند).
4. همهٔ تغییرات کاربرمحور در [`CHANGELOG.md`](CHANGELOG.md) ثبت می‌شود.
5. نقشهٔ راه با چک‌باکس به‌روز می‌شود؛ هر مورد تکمیل‌شده به commit یا PR پیوند دارد.
