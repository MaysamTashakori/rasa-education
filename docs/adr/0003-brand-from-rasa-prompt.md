# ADR 0003 — هویت بصری از خانوادهٔ رسا
- وضعیت: پذیرفته · تاریخ: ۱۲ آبان ۱۴۰۵
- زمینه: کاربر خواست طراحی از rasa-prompt.ir الهام بگیرد.
- تصمیم: پالت black-yellow (`#050505`، `#121212`، `#414141`، `#F4D438`)، قلم Vazirmatn، کارت‌های خط‌دار گوشه‌گرد و برچسب‌های شماره‌دار. نشان اختصاصی رسا آموزش با همان امضای «سه نوار» ولی متمایز طراحی شد.
- پیامد: تم‌های قبلی (کهکشانی، اقیانوس) به عنوان تم انتخابی حفظ شدند؛ پیش‌فرض «رسا · شب».
