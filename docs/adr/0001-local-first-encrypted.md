# ADR 0001 — داده روی دستگاه و رمزگذاری‌شده (Local-first)
- وضعیت: برای برنامه‌ریز تک‌فایلی پذیرفته؛ برای سامانه با ADR 0004 جایگزین شد · تاریخ: ۱۲ آبان ۱۴۰۵
- زمینه: کاربر خواست «دیتابیس روی گوشی یا کامپیوتر» باشد؛ اینترنت ایران ناپایدار است و داده‌های تحصیلی کودک حساس است.
- تصمیم: منبع اصلی داده IndexedDB روی دستگاه، رمزگذاری‌شده با کلید مشتق از رمز کاربر. سرور آینده فقط همگام‌سازی رمزدار و اختیاری انجام می‌دهد.
- پیامد: رمز قابل بازیابی نیست؛ پشتیبان‌گیری باید آسان و پیش‌فرض باشد (پشتیبان خودکار روزانه).
