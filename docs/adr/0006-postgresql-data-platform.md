# ADR 0006 — PostgreSQL به‌عنوان دیتابیس اصلی
- وضعیت: پذیرفته (اجرای مرحله‌ای) · تاریخ: ۱۵ آبان ۱۴۰۵
- زمینه: بنیان‌گذار «بهترین دیتابیس» و ارائهٔ خدمات SaaS و AIaaS خواست. SQLite فعلی برای یک سرور کافی است، اما چندمستأجری، جست‌وجوی معنایی، صف کار ایجنت‌ها و همزمانی بالا را خوب پشتیبانی نمی‌کند.
- تصمیم: PostgreSQL 16 + pgvector + pg_trgm؛ RLS برای جداسازی مستأجر؛ MinIO برای فایل؛ صف کار در خود Postgres. SQLite برای توسعهٔ محلی می‌ماند. جزئیات: [12-data-platform.md](../12-data-platform.md).
- پیامد: یک وابستگی (`pg`) به سرور اضافه می‌شود. استقرار به docker compose (app + postgres + minio) تغییر می‌کند. مهاجرت مرحله‌ای و بدون از دست رفتن داده انجام می‌شود.
