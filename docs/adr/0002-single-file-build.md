# ADR 0002 — ساخت تک‌فایلی بدون وابستگی
- وضعیت: پذیرفته · تاریخ: ۱۲ آبان ۱۴۰۵
- زمینه: کاربر «اول فایل تکی، بعد سامانه» خواست؛ فایل باید آفلاین و خودکفا باشد.
- تصمیم: کد به صورت جاوااسکریپت خالص در چند فایل منبع؛ `build.mjs` (بدون npm dependency) فونت، CSS، کاتالوگ و JS را در یک HTML جاسازی می‌کند و نسخهٔ PWA را هم می‌سازد.
- پیامد: بدون فریم‌ورک؛ در فاز ۲ ماژول‌ها می‌توانند به ES modules یا یک فریم‌ورک منتقل شوند، با حفظ قرارداد داده.
