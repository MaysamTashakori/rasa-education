# ADR 0004 — سامانهٔ کلاس دوم ابتدایی پیش از کنکور
- وضعیت: پذیرفته · تاریخ: ۱۲ آبان ۱۴۰۵
- زمینه: کاربر گفت مخاطب فعلی «کلاس دوم ابتدایی» است؛ برنامه‌ریز قبلی دبیرستانی بود و ابزار مخصوص این پایه نداشت. کنکور و تراز «بعداً یک برنامهٔ دیگر» خواهد بود. کاربر با سرور مشکلی ندارد و سامانهٔ وب‌اپ با ثبت‌نام رایگان، چند درس و اتصال به مارکت خواست.
- تصمیم: سامانهٔ سروری (حساب والد + چند فرزند، SQLite) با ابزارهای کلاس دوم: روال روزانه و ستاره، دفتر مشق، کیف فردا از روی برنامهٔ کلاسی، کتاب‌خوانی، جایزهٔ والد با رمز والد، ۱۱ درس تعاملی رایگان (ریاضی، فارسی، علوم) و بازار با کاربرگ‌های چاپیِ تولیدشونده. ماژول بازار جدا (API `market/*` و `content/grade2/market.json`) تا به مارکت‌پلیس اصلی وصل شود.
- پیامد: ADR 0001 (فقط داده روی دستگاه) برای این سامانه جایگزین می‌شود؛ داده روی سرور خانواده است و نسخهٔ محلی فقط کش آفلاین است. برنامه‌ریز دبیرستان در `/planner/` به‌عنوان نسخهٔ آزمایشی می‌ماند.
