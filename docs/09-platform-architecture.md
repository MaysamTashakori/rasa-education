# معماری پلتفرم رسا آموزش (نسخهٔ بزرگ)
> وضعیت: طراحی · آخرین بازبینی: ۱۲ آبان ۱۴۰۵ · فعلاً همه‌چیز رایگان

## اصول
سهولت کار، خلاقیت، یادآوری و اطلاع‌رسانی به والد و کودک در **بله** و **تلگرام**؛ هوش مصنوعی در سایت اصلی؛ مجموعهٔ ایجنت‌ها برای مدیریت پلتفرم؛ مارکت‌پلیس حرفه‌ای که موتور توسعه‌دهندگان جزوه و گزارش تعاملی است.

## نقش‌ها
| نقش | دسترسی |
|---|---|
| کودک | امروز، مشق، درس‌ها، بازار (مشاهده/دریافت رایگان)، ستاره‌ها |
| والد | همهٔ موارد کودک + داشبورد، جایزه، برنامهٔ کلاسی، اعلان‌ها، چند فرزند |
| معلم/مشاور (آینده) | مشاهدهٔ گزارش با اجازهٔ والد |
| فروشنده/توسعه‌دهنده | پنل سازنده: ساخت جزوه/گزارش تعاملی با SDK، پیش‌نمایش، انتشار، آمار |
| ناظر محتوا | صف بازبینی محصولات و گزارش تخلف |
| پشتیبان | تیکت‌ها و حساب‌ها (فقط‌خواندنی دادهٔ آموزشی) |
| مدیر کل | مرکز کنترل و فرماندهی: کاربران، نقش‌ها، محصولات، ایجنت‌ها، پایش |

## اعلان‌ها (بله و تلگرام)
- اتصال حساب: والد در پنل «اتصال به بله/تلگرام» یک کد یک‌بارمصرف می‌گیرد و به ربات می‌فرستد (`/start <code>`).
- ربات‌ها: Telegram Bot API و Bale Bot API (سازگار با همان قالب)، webhook روی `/api/bots/{telegram|bale}`؛ توکن‌ها فقط در متغیر محیطی.
- رویدادها: یادآور روال (صبح/عصر)، مشق فردا، کیف فردا، پایان کتاب‌خوانی، گزارش هفتگی والد، رسیدن به جایزه، محصول جدید بازار.
- صف ارسال با تلاش مجدد و ساعت سکوت (۲۱ تا ۷).

## ایجنت‌های مدیریت پلتفرم
| ایجنت | کار |
|---|---|
| مربی کودک | پیشنهاد روزانهٔ تمرین بر اساس خطاها و ستاره‌ها |
| گزارشگر والد | خلاصهٔ هفتگی طبیعی و قابل فهم برای بله/تلگرام |
| سازندهٔ محتوا | پیش‌نویس درس و کاربرگ برای بازبینی معلم |
| ناظر محتوا | بررسی کیفیت، تطابق پایه و ایمنی کودک |
| مدیر بازار | دسته‌بندی، برچسب، پیشنهاد محصول |
| پشتیبان | پاسخ به پرسش‌های والدین |
| پایشگر سامانه | سلامت سرور، خطاها، پشتیبان پایگاه داده |
همهٔ ایجنت‌ها خروجی را برای تأیید انسانی در مرکز کنترل ثبت می‌کنند؛ هیچ ایجنتی مستقیم به کودک پیام نمی‌دهد.

## مارکت‌پلیس
- صفحهٔ محصول با **پیش‌نمایش زنده** (اجرای نمونه در sandbox)، دریافت با یک کلیک، کتابخانهٔ خانواده.
- پروفایل سازنده، امتیاز و نظر، آمار استفاده.
- **SDK سازنده:** قالب JSON (`content/*`) + کامپوننت‌های تعاملی (پرسش، چینش، ساعت، شمارش، گزارش نمودار) تا توسعه‌دهندگان جزوه و گزارش تعاملی بسازند.
- قیمت‌گذاری فعلاً صفر؛ ساختار سفارش و درگاه برای بعد آماده است.

## مرکز کنترل و فرماندهی
داشبورد زنده: کاربران فعال، اعلان‌های ارسالی، صف بازبینی، وضعیت ایجنت‌ها، خطاها، محصولات پرطرفدار؛ مدیریت نقش‌ها و ممیزی (audit log).

## مراحل
1. نقش‌ها و جدول `roles` + audit log · 2. ربات‌های بله و تلگرام · 3. مرکز کنترل · 4. پنل سازنده و پیش‌نمایش · 5. ایجنت‌ها (با کلید API هوش مصنوعی از متغیر محیطی).
